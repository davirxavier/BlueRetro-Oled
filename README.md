# BlueRetro

<p align="center"><img src="/static/PNGs/BRE_Logo_Color_Outline.png" width="600"/></p>
<br>
<p align="justify">BlueRetro is a multiplayer Bluetooth controllers adapter for various retro game consoles & computers. Lost or broken controllers? Reproduction too expensive? Need those rare and obscure accessories? Just use the Bluetooth devices you already got! The project is open source hardware & software under the CERN-OHL-P-2.0 & Apache-2.0 licenses respectively. It's built for the popular ESP32 chip. Wii, Switch, PS3, PS4, PS5, Xbox One, Xbox Series X|S & generic HID Bluetooth (BR/EDR & LE) devices are supported. Parallel 1P (Computers, NeoGeo, Supergun, JAMMA, Handheld, etc), Parallel 2P (Atari 2600/7800, Master System, Computers, etc), NES, PCE / TG16, Mega Drive / Genesis, SNES, CD-i, 3DO, Jaguar, Saturn, PSX, PC-FX, JVS (Arcade), Virtual Boy, N64, Dreamcast, PS2, GameCube & Wii extension are supported with simultaneous 4+ players using a single adapter.</p>

## Custom Features

This fork introduces additional hardware features and a custom user interface to enhance the BlueRetro adapter experience.

### OLED Display
- [x] Added a 0.9-inch OLED display.
- [x] Display connected controllers in a player list.
- [x] Display individual controller battery percentages.
- [x] Battery monitoring for PS4 controllers and DualSense controllers (currently the only controllers tested, only ones i have at hand).
- [ ] Full graphical user interface directly on the OLED display.
- [ ] Built-in controller button tester.
- [ ] Configuration options accessible through the display.
- [x] Two-button navigation and interaction system for controlling the interface.

### Audio Feedback
- [x] Buzzer for audible feedback.
- [x] Sound effects for interactions.
- [ ] Audible low-battery warning.

### WS2812 LED
- [x] Replaced the original four LEDs with a single WS2812 addressable LED with multiple color feedbacks.

### Planned Features
- [ ] Complete OLED graphical interface.
- [ ] Controller button testing interface.
- [ ] Configuration menu accessible through the OLED.
- [ ] Full interface navigation using the two physical buttons.
